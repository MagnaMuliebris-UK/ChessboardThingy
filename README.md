WHY WAS THIS MADE?
Some company decided to posit a coding challenge for their interview process and it was honestly boring...so I decided to pick it up and make it more fun for me. Mostly by scopecreeping it until I was happy...also because I sort of forgot the rules. Hell, you only had an NxN plane with obstructions and one Queen

HOW BORING

so now there's multiple queens, (possibly) rectangular board patterns, and saving progress (and capturable queens too ;})

I guess this is a rudimentary system to eventually make an infinitely scaling chessgame but...eh that's another thing entirely. I MIGHT do that, but if I do, its not going to be in this now.

HOW DOES THIS WORK?
In short, 'matrices' and simple position checking. Very boring, very simple. For loops. Also objects and lists. Chess is just a matter of objects, matrices, and position checking at the end of the day.

Is there a piece here? Is it mine? How does my piece move? Where is my piece? There is surely a better way but...I'm unaware of it, so this rudimentary system is good enough.
